# 首頁內容區塊規格

## 目標

在首頁 Banner 後補上品牌介紹、近期活動、近期課程與聯絡資訊，讓第一次造訪的使用者依序理解空間理念、可參與的內容及聯絡方式。第一版以示範資料確認視覺與資訊順序，版面確認後再建立 Sanity schema。

## 區塊與內容

- 圖文介紹：一張情境圖片、段落標籤、標題與兩段品牌介紹。
- 近期活動：最多三筆，呈現月份、日期、類型、名稱與時間。
- 近期課程：兩筆主要課程，呈現圖片、課程類型、名稱與摘要。
- 聯絡我們：簡短邀請文字與電子郵件入口。

## 驗收條件

1. 首頁內容順序為 Banner、圖文介紹、近期活動、近期課程、聯絡我們。
2. 桌面版導覽可移動至各內容區塊；鍵盤操作時連結具有清楚的焦點樣式。
3. 手機版維持單欄閱讀順序，文字不超出畫面，互動區域至少 48px 高。
4. 圖片提供替代文字並延遲載入；頁面標題階層由一個 `h1` 與各區 `h2` 組成。
5. 視覺延續暖白、陶土與棕色，主要樣式使用 Tailwind CSS。

## 後續資料化

版面確認後，分別為品牌介紹、活動、課程與聯絡資訊建立 Sanity 文件或單例設定。活動與課程列表需定義顯示規則，例如依日期排序、只呈現已發布且尚未結束的項目。

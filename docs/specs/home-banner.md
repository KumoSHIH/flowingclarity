# 首頁 Banner 功能規格

## 目標

讓具有 Sanity Studio 編輯權限的成員維護首頁 Banner；訪客在 `web` 首頁看到大標題、摘要，以及一組可切換的圖片與敘述。

## 內容模型

- Banner 是固定的一份文件，包含必填的大標題、摘要與「輪播內容」。
- 輪播內容至少一筆；每筆包含圖片、圖片替代文字與敘述文字，皆為必填。
- 編輯者在 Studio 調整項目順序，前台依該順序顯示。
- 本次不包含排程發布或圖片連結。

## 驗收條件

1. 編輯者可新增、刪除及重排圖片與敘述；缺少必填內容時無法發布。
2. 發布後重新開啟首頁，看到最新的大標題、摘要，以及每張圖片對應的敘述。
3. 多張圖片時，每張停留 2500ms 後自動播放下一張，並以 800ms 淡入淡出；播至最後一張後回到第一張。觸控滑動或鍵盤方向鍵也可切換，互動後仍繼續自動播放。畫面不顯示左右切換按鈕，頁碼隨之更新。
4. 每張圖片的敘述顯示在圖片右下角。只有一張圖片時不自動播放，也不顯示頁碼。
5. 未發布的草稿修改不出現在公開首頁。
6. 已發布的舊版單張圖片 Banner 在加入新輪播內容前仍可顯示；其摘要暫作圖片敘述。
7. 沒有可用的已發布 Banner 或讀取失敗時，首頁顯示示範 Banner，不出現破版。
8. 手機版（小於 768px）Banner 先顯示輪播圖片，下方接大標題與摘要；768px 以上採左側文字、右側圖片的雙欄版面。

## 實作順序

1. 擴充 Sanity schema 為可排序的輪播項目。
2. 在 web 使用 Swiper 顯示圖片與敘述，並以 Tailwind utility 實作版面。
3. 更新讀取資料的 API，處理新輪播資料與已發布的舊版 Banner。
4. 驗證 Studio 發布與前台顯示流程。

# About UI 驗收

**日期：** 2026-10-18  
**狀態：** `ui-verified`

## 驗收範圍

以 production build 搭配 Chromium 檢查 `/about` 的 320、390、768、1024、1440px，以及 720px 的 200% 縮放等效寬度。確認內容順序、字級、桌機與手機間距、水平溢位、圖片替代文字、焦點樣式、觸控操作區、輪播循環、暫停條件、reduced motion 與長內容換行。

## 結果

- 所有檢查寬度皆無頁面水平溢位；320px 下主要控制與聯絡連結均至少 44 × 44px。
- 頁面維持單一 `h1`，圖片無載入失敗或缺漏替代文字；桌機聯絡區上距 150px，手機為 50px。
- 輪播只有上一張／下一張按鈕，沒有播放控制；可首尾循環，快速重複操作會在轉場完成前鎖定，並保留鍵盤焦點。
- hover、控制項 focus、頁籤不可見與 reduced motion 會停止自動播放；reduced motion 轉場縮短為 0.001s。
- 修正淺色表面的輔助文字對比、聯絡連結最小操作區，以及快速切換可能越過 clone 索引的問題。

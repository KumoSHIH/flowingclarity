本輪只探索課程詳情頁的「課程梯次」區塊，不修改正式 Vue 元件。三案沿用暖紙、細線、深赭色、藏紅花狀態與直角主要行動，並使用三階段、每階兩段日期的長內容壓力測試；所有日期、費用與地點皆為版面示意，非正式招生資訊。

## 方向比較

- A「階序長卷」：以垂直階序和完整日期列為核心，閱讀最直覺，也最容易支援階段說明長短差異。[預覽圖](./a-1440.png)
- B「夜色課程帶」：以深色沉浸表面並列三階，最能建立完整訓練旅程的整體感，但階段數增加時需改為水平捲動或換列。[預覽圖](./b-1440.png)
- C「編輯式行程簿」：左側集中梯次決策資訊，右側以精準日期簿展開，資訊效率最高，也最適合多梯次內容。[預覽圖](./c-1440.png)

可開啟[互動比較頁](../../course-schedule-concepts-desktop.html)，用頂端頁籤切換三案；也可在網址加上 `?concept=a`、`?concept=b` 或 `?concept=c` 直接指定版本。

- 已用 Chrome 以 1440 × 1400 px 實際渲染三案，中文字型、日期欄位、分隔線與按鈕皆正常顯示。
- 版面檢測器針對 layout scope 掃描結果為 0 項問題。
- 三案皆完整顯示三階段與六段日期，沒有把分階日程誤縮成單一起訖區間。
- 新版極簡稿已依正式頁手動調整同步為 900px 最大內容寬度；正式梯次區使用完整視窗高度垂直置中，桌機標題固定為 58px，layout scope 掃描結果為 0 項問題。
- 正式 `CourseDetail` 元件已用 Chrome 以 1440 × 1000 px 與 CDP 精確 390 × 1100 px 驗收；390px 實測 `innerWidth`、`clientWidth`、`scrollWidth` 均為 390px。第一階上方沒有分隔線，手機標題、說明、六段日期與全寬 CTA 均無裁切。

- 正式梯次於 1440 × 1000 px 實測內層寬 900px、區塊高 1000px；390px 實測 `innerWidth`、`clientWidth`、`scrollWidth` 均為 390px。地點、三欄資訊標籤、底部提醒及 CTA 已與極簡稿一致。

# 文章分享總覽桌機三案

2026-10-15 依 [`articles.md`](../../../specs/articles.md) 製作三個 1440px 桌機概念稿。本輪只比較資訊構圖，三案皆沿用現有 Header、暖紙／淺砂／深赭色域、繁中襯線標題、直角平面表面，以及四個固定主要分類、多選相關標籤、每頁 8 篇的內容契約。稿中文字與圖片皆為排版示意，不是核准的正式文章內容。

- **A｜雙頁主題索引：** 左側集中頁面身份與篩選，右側由一篇大型焦點文章帶出緊湊文章索引。閱讀入口最直接，但焦點文章在正式實作時仍須遵守發布日期排序。
- **B｜四域閱覽室：** 四個主要分類直接構成頁面骨架，選取分類展開文章長列，標籤維持獨立控制帶。分類辨識最強，但後續須驗證展開互動不會妨礙鍵盤操作。
- **C｜文章地層長譜：** 篩選置於首屏上方，文章沿中央時間地層交錯排列。日期與主題的節奏最鮮明，但必須保留明確分頁，不改成無限捲動。

三張 WebP 均已確認為非空白橫向桌機畫面：A 為 1440×960、B 為 1440×1000、C 為 1440×1024；完整生成 prompt 與同名圖片並列保存。

## 選定方向與手機延伸

使用者選定 C「文章地層長譜」，並要求示意日期使用同一年度；核准桌機稿的三筆日期均為 2026 年，後續 fixture 也必須維持單一年度。手機稿 [`articles-strata-score-mobile.webp`](articles-strata-score-mobile.webp) 以核准桌機稿為參考產出，尺寸為 850×1851：Header 改用選單按鈕，主要分類與 checkbox 標籤自然換行，中央地層線移至左側 rail，三篇文章依 DOM 順序垂直排列，日期均為 2026 年，末端保留每頁 8 篇與頁碼。

目前已完成桌機／手機視覺方向與 surface brief，規格更新為 `design-approved`。尚未驗證實際互動、HTML 語意、鍵盤焦點、320／768／1023px 中間尺寸、長內容、空／錯誤狀態或瀏覽器差異；這些項目由後續前端原型與 UI 驗證階段完成。

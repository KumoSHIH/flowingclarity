# 文章詳情 Banner 左側與圖文區塊桌機稿（第三輪）

本輪固定中央大標題、摘要與右側直幅代表圖，只比較 banner 左側文章資訊及正文圖文區塊。三案皆涵蓋一組左圖右文、一組右圖左文及一張滿寬圖片，直接對應既有 `splitMediaSection.mediaSide` 與 `wideImageSection`，沒有新增內容欄位。

- A「紙頁展卷」：暖砂資訊牌；正文以圖文交替的完整跨頁建立平穩節奏。
- B「日期軸線」：大日期成為左側主體；正文圖片向頁邊延伸，文字維持固定閱讀軸。
- C「深色座標」：深赭資訊面板；正文以大幅圖像與相鄰文字面板形成沉浸章幅。

驗證尺寸為 1440px 桌機。`a-1440.png`、`b-1440.png`、`c-1440.png` 為 1440 × 1100 首屏；`*-1440-full.png` 為 1440 × 4300 長頁。截圖使用 reduced-motion，已確認三案從頁首開始、左右圖文與滿寬圖片皆出現，且完整涵蓋延伸閱讀與 Footer。

Finish review 最終 disposition 為 `ship`：本輪六張截圖與三案比較稿可交付選案。`ship` 不代表已選定方向，也不建立設計核准；文章詳情規格仍為 `draft`。下一步是由使用者選定 A／B／C，再延伸手機版與缺少選填內容等狀態；Vue 實作與 Sanity 串接均延後至選案後。

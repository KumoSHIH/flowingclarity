# 文章分享總覽頁規格

**狀態：** verified
**路由：** `/articles`  
**頁面模式：** Browse；依主要分類與相關標籤篩選並分頁瀏覽文章  
**設計依據：** [`PRODUCT.md`](../../PRODUCT.md)、[`DESIGN.md`](../../DESIGN.md)、[`course.md`](course.md)，以及已核准的 C「文章地層長譜」[桌機稿](../design/review/articles-page-concepts-desktop/articles-strata-score.webp)與[手機稿](../design/review/articles-page-concepts-desktop/articles-strata-score-mobile.webp)

## 目標與受眾

主要受眾是想先透過文章理解身心主題、課程背景或帶領經驗，再判斷是否繼續探索課程的訪客。頁面需讓訪客快速看懂有哪些文章主題、目前篩選條件與文章重點，並能進入單篇文章閱讀。

成功標準是訪客可在不搜尋的情況下，先以四個主要分類理解文章方向，再用可多選的相關標籤縮小文章集合、透過頁碼繼續瀏覽，且重新整理、分享網址或使用瀏覽器上一頁後仍保留相同篩選與頁碼。

## 範圍與非目標

第一版包含共用 Header／Footer、頁面標題與導讀、全部文章與四個主要分類的單選篩選、可多選的相關標籤篩選、已發布文章列表、URL 可還原的分頁，以及 loading、empty、error、缺圖與長內容狀態。主要分類固定為「愛身體、撫慰心、究生命、展現美」，沿用既有課程分類定義；後台不得新增第五個主要分類。相關標籤則是可由後台新增、命名及排序的獨立 taxonomy，可使用「頭薦骨」、「人類圖」等課程主題，也可新增「家族系統排列」等非課程主題。

第一版不包含關鍵字搜尋、多個主要分類同時篩選、熱門排序、收藏、留言、會員、社群分享統計、推薦演算法、站內文章編輯預覽流程，以及標籤與課程文件的自動同步。單篇文章頁 `/articles/[slug]` 的內容版型、正文模型與延伸閱讀不在本規格內；總覽只定義進入該路由所需的摘要資料。

## 已確認事實、工作假設與示範內容

- 已確認：公開總覽路由為 `/articles`，全站導覽已有「文章分享」入口。
- 已確認：主要分類固定為四個，分別是「愛身體、撫慰心、究生命、展現美」；訪客一次可選一個主要分類。
- 已確認：另有「相關標籤」篩選區，訪客可同時選擇多個標籤。標籤可使用主題課程名稱，也可由後台自行新增，例如「家族系統排列」。
- 已確認：每篇文章屬於一個主要分類，並可關聯多個相關標籤。
- 已確認：Sanity 是正式內容來源；既有四個課程分類 schema 可供共用，但目前尚無文章、文章標籤 schema、公開頁面或核准正式文章內容。
- 工作假設：主要分類直接 reference 既有固定 `courseCategory`，不建立第二套名稱相同的文章分類文件。
- 工作假設：`articleTag` 是獨立 taxonomy；使用課程名稱不代表自動 reference 或同步該課程。若日後需要從標籤直接導向課程，再新增明確的選填課程關聯。
- 工作假設：多選標籤採 OR 聯集，文章符合任一已選標籤即可；主要分類與標籤之間採 AND 交集。若同時選擇「愛身體」及「頭薦骨、人類圖」，結果需屬於愛身體，且至少具有頭薦骨或人類圖其中一個標籤。
- 工作假設：公開文章預設依 `publishedAt` 由新到舊排列，同時間再以穩定文件 ID 排序；不提供人工置頂或自訂排序。
- 工作假設：每頁固定顯示 8 篇；分類切換會回到第 1 頁。
- 示範內容：設計或測試階段可使用明確標示的 fixture 驗證長度與狀態，但不得把文章標題、摘要、日期、作者或圖片視為正式內容。

## 資訊架構與顯示規則

1. `SiteHeader` 從載入起顯示並標示 `/articles` 為目前頁面，主內容只有一個 `h1`。
2. 頁面先呈現標題與導讀，再依序提供主要分類、相關標籤及文章結果。主要分類固定依既有 `courseCategory.order` 顯示；標籤依 `articleTag.order` 升冪排列，同序時以名稱及穩定文件 ID 排序。
3. 「全部文章」為主要分類預設條件；選擇分類後只顯示該分類的已發布文章。四個主要分類入口固定保留，即使某分類暫無文章也顯示可理解的空狀態，不因內容數量改變產品架構。
4. 相關標籤可選 0–8 個；只有已發布且至少被一篇公開文章使用的標籤出現在前台。選取多個標籤時採 OR 聯集；若另選主要分類，再與分類條件做 AND 交集。提供一次清除全部標籤的操作，清除標籤不改變目前主要分類。
5. URL 使用 `category=<category.key>`、可重複的 `tag=<tag.slug>` 與 `page=<正整數>`，例如 `/articles?category=body&tag=craniosacral&tag=family-constellations&page=2`。全部文章、未選標籤及第 1 頁省略相應 query。任何分類或標籤變更都將 `page` 重設為 1；重新整理、分享連結及瀏覽器上一頁／下一頁需還原狀態。
6. 無效 `category` 回到全部文章；無效、重複或超過 8 個的 `tag` 值會被忽略或去重；非正整數或超出範圍的 `page` 正規化至目前結果的有效頁，不呈現空白頁。canonical URL 依主要分類、標籤排序及頁碼產生一致參數順序。
7. 完成主要分類與標籤過濾後，再依發布日期排序並分頁。每頁 8 篇；只有一頁時不顯示頁碼控制。文章新增、下架、改分類、改標籤或發布日期變更後，頁數及項目位置依公開資料重新計算。
8. 每筆文章顯示主要分類、相關標籤、標題、摘要、發布日期與選填代表圖，整筆主要入口連到 `/articles/{slug}`。列表不顯示不存在的作者、閱讀時間或未定義的課程關聯。

### 主要分類

| 欄位 | 語意與型別 | 必填與合理範圍 | 編輯責任／預定來源 |
| --- | --- | --- | --- |
| `key` | 不受顯示名稱影響的穩定識別碼 | 必填且唯一，固定 `body`、`heart`、`life`、`beauty` | 既有課程分類定義／Sanity `courseCategory` |
| `name` | 對外顯示的主要分類名稱 | 必填且固定為愛身體、撫慰心、究生命、展現美 | 既有課程分類定義／Sanity |
| `order` | 主要分類顯示順序 | 必填且固定為 1–4 | 既有課程分類定義／Sanity |
| `summary` | 課程分類的學習方向摘要 | 既有必填欄位；文章總覽第一版不顯示 | 課程編輯者／Sanity |

文章不建立獨立 `articleCategory`，而是以 reference 沿用既有四個 `courseCategory` 文件。分類 identity、名稱及順序依既有 schema 鎖定，文章編輯器不得建立新分類。此關聯只共用四個學習方向，不代表文章必須關聯某一門課程。

### 相關標籤

| 欄位 | 語意與型別 | 必填與合理範圍 | 編輯責任／預定來源 |
| --- | --- | --- | --- |
| `name` | 對外顯示的標籤名稱，例如頭薦骨、人類圖、家族系統排列 | 必填，2–20 字；全體標籤名稱不可重複 | 編輯者／Sanity `articleTag` document |
| `slug` | URL 與 reference 使用的穩定識別碼 | 必填且全體標籤唯一，1–60 個小寫英數與連字號；建立後不應任意更改 | 編輯者／Sanity |
| `order` | 標籤篩選器顯示順序 | 必填，正整數；同一值仍有穩定次排序 | 編輯者／Sanity |
| `description` | 標籤涵蓋範圍的編輯說明 | 選填，10–100 字；第一版總覽不顯示 | 編輯者／Sanity |

標籤以 Sanity 文件的 draft／published 狀態管理公開性，不另設 `isPublished`。課程名稱與自行新增的主題使用相同 `articleTag` 模型，不以標籤型別改變前台行為，也不自動複製或同步 `course` 文件。已被文章引用的標籤不得直接刪除；編輯者需先移除文章 reference 或下架相關文章。更名不改變 slug；若必須修改 slug，需另定重新導向策略。

### 文章摘要資料

| 欄位 | 語意與型別 | 必填與合理範圍 | 編輯責任／預定來源 |
| --- | --- | --- | --- |
| `title` | 文章正式標題，純文字 | 必填，4–50 字 | 編輯者／Sanity `article` document |
| `slug` | 單篇文章穩定識別碼 | 必填且文章內唯一，1–80 個小寫英數與連字號 | 編輯者／Sanity |
| `category` | 文章主要分類 reference | 必填且僅 1 個；只可選既有四個 `courseCategory` | 編輯者／Sanity |
| `tags` | 文章相關標籤 references | 必填且不可重複；最少 1、典型 1–3、最多 8 個 `articleTag` | 編輯者／Sanity |
| `excerpt` | 協助訪客判斷是否閱讀的摘要，純文字 | 必填，30–140 字；不得只複製標題 | 編輯者／Sanity |
| `publishedAt` | 對外發布日期時間 | 必填，ISO datetime；不可晚於實際首次公開時間 | 編輯者／Sanity |
| `coverImage` | 選填代表圖，含裁切焦點 | 選填；有內容意義時 `alt` 必填 2–120 字 | 編輯者／Sanity image |

文章同樣依 Sanity draft／published 狀態決定是否公開，不另設第二個公開開關。只有文章、主要分類及至少一個標籤皆已發布，且 slug、標題、摘要與日期完整的資料可進入列表；未發布的個別標籤不顯示也不參與篩選，但文章仍可由其他已發布標籤被找到。資料不完整時不以 fixture 補位。日期由 `publishedAt` 格式化，不另存顯示字串。

## 狀態與行為

- **一般：** 預設顯示全部文章第 1 頁且不選標籤；目前主要分類、已選標籤及頁碼有文字或語意標示，不只依賴顏色。
- **Loading：** 保留頁面身份與篩選區輪廓，文章區使用低對比骨架並設 `aria-busy="true"`；不朗讀每個骨架項目。
- **完全空：** 顯示 `emptyMessage`，保留四個主要分類作為產品方向，但不顯示無資料標籤、0 筆計數、空頁碼或示範文章。
- **篩選結果空：** 保留目前主要分類與標籤選取狀態，說明沒有符合條件的文章，並提供清除標籤及返回「全部文章」的操作。
- **Error：** 保留 Header、頁面標題與 Footer，說明文章暫時無法載入並提供重新載入；不得回退成 fixture。
- **缺少選填內容：** 無代表圖時使用不含文字的品牌平面表面或讓文字自然擴展，不顯示破圖；不渲染空 alt 以外的虛構描述。
- **長內容：** 50 字標題、140 字摘要、20 字標籤、單篇 8 個標籤及 200% 文字放大不得造成截斷、重疊或水平捲動；第一版不以省略號隱藏必要內容。
- **篩選：** 分類或標籤操作後更新 URL、回到第 1 頁，並將焦點移至結果標題；選取或取消單一標籤不清除其他標籤，切換主要分類也保留已選標籤。若需重新請求，保留篩選器與既有結果至新資料完成，失敗時維持原狀並說明。
- **分頁：** 提供上一頁、下一頁與可辨識的頁碼；五頁以內顯示全部頁碼，超過五頁保留首尾與目前頁附近頁碼。不可用控制項使用原生 disabled 語意；切頁後更新 URL 並將焦點移至結果標題。
- **互動回饋：** 文章入口、主要分類、標籤與頁碼都有等價的 hover／`focus-visible` 狀態；標籤選取狀態需可直接辨認，不得將多個連結互相巢狀。

## 響應式與視覺約束

- 延續 `DESIGN.md` 的暖紙、淺砂、深赭色域、繁中襯線標題、無襯線內文、直角與平面表面；不新增圓角卡片、陰影、柔焦療癒圖或大面積柿橘背景。
- 桌面採 C「文章地層長譜」：標題、導讀、主要分類與標籤帶之後，以中央細線將文章依發布日期交錯安置在兩側；日期、分類、標籤、標題與摘要保持可比較的位置。構圖不得改回通用等寬卡片網格或無限捲動。
- `<= 1023px` 使用單欄閱讀，地層線移至左側內容 rail，文章不再左右交錯；資訊順序固定為頁面身份、主要分類、標籤、結果、文章、分頁。四個主要分類與動態增加的標籤允許自然換行；標籤過多時可使用具可見狀態的展開／收合控制，不得只提供無提示的橫向滑動，也不得截掉標籤名稱。
- 主要內容左右留白沿用 `clamp(28px, 6vw, 116px)`；所有互動目標至少 44 × 44px。
- 至少驗證 1440、1023、768、390、320px 及 200% 文字放大。動態只用於狀態提示，且遵守 `prefers-reduced-motion`。

## 語意、鍵盤與替代文字

`main` 內只有一個 `h1`；主要分類與相關標籤為兩組有可理解名稱的篩選控制，標籤多選使用 checkbox 等原生多選語意，不假裝成單選 tab。文章結果為具可見標題的 `section`，文章集合使用 `<ul>`／`<ol>`，每篇標題使用一致的下一層 heading。發布日期使用 `<time datetime>`。主要分類若導向可分享網址使用原生連結；清除標籤與重新載入使用 `<button>`。鍵盤、視覺及 DOM 順序一致，焦點不得因資料更新而遺失。

代表圖若補充文章內容，alt 描述畫面提供的資訊且不重複標題；純裝飾圖使用空 alt。結果更新以簡短 live region 通知分類與結果狀態，不重讀整份列表。頁碼需有可理解的無障礙名稱，省略號不是可聚焦控制項。

## 驗收條件

1. `/articles` 使用共用 Header／Footer，Header 正確標示目前頁，主內容只有一個 `h1`。
2. 主要分類固定沿用四個 `courseCategory`：愛身體、撫慰心、究生命、展現美；文章後台只能選擇其中一個，不能新增第五個主要分類。
3. 後台可新增 `articleTag`，課程名稱標籤與「家族系統排列」等自訂標籤使用同一模型；發布後無需前端改碼即可出現在相關標籤篩選器。
4. 每篇文章必須有一個主要分類及 1–8 個不重複標籤。只有文章與主要分類皆已發布且必要摘要資料完整的文章出現在列表；draft、孤立 reference 或不完整資料不顯示。
5. 選取多個標籤時結果符合任一標籤；同時選擇主要分類時，結果還必須屬於該分類。切換分類保留標籤，任何篩選變更都回到第 1 頁。
6. `category`／重複 `tag`／`page` query 可分享、重新整理及由瀏覽器歷史還原；無效、重複或超量值會正規化且不產生空白頁。
7. 預設依 `publishedAt` 新到舊排序；相同日期仍有穩定順序。完成分類與標籤過濾後，再以每頁 8 篇分頁。
8. 完全空、篩選結果空、loading、error、缺圖及長內容都有清楚呈現，不以 fixture 或破圖補位；空結果可清除標籤或返回全部文章。
9. 只有一頁時不顯示頁碼；多頁可用滑鼠、觸控與鍵盤操作，切頁後焦點與結果更新通知正確。
10. 每篇文章顯示主要分類、相關標籤、標題、摘要與發布日期，並以有效 slug 連到 `/articles/[slug]`；不顯示未定義的作者、閱讀時間或課程關聯。
11. 320–1440px 與 200% 文字放大無水平溢位或內容裁切，8 個文章標籤及大量篩選標籤可換行或存取，互動目標至少 44px，焦點與選取狀態不只依顏色。
12. heading、list、link、button、checkbox 與 `time` 語意正確；有意義圖片具有合適 alt，裝飾圖為空 alt，reduced-motion 設定受到尊重。
